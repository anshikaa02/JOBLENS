# JobLens – AI Resume Analyzer & Job Matcher

##  Overview
JobLens is an AI-powered web application designed to help job seekers optimize their resumes and improve their chances of passing Applicant Tracking Systems (ATS). The platform analyzes uploaded resumes, provides ATS compatibility scores, identifies missing skills, and matches resumes with relevant job descriptions.

## Planned Features

- 📄 Resume upload (PDF)
- 🤖 AI-powered resume analysis
- 📊 ATS compatibility score
- 🎯 Skill gap analysis
- 💼 Job matching based on resume
- 📈 Resume improvement suggestions
- 📑 Resume parsing and keyword extraction
- 🔍 Job description comparison
- 🌐 Responsive and modern web interface
